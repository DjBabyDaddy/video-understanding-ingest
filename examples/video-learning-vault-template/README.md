# Video Learning Vault Template

Point `VIDEO_LEARNING_VAULT` at a copy of this folder if you want Obsidian notes from `video_digest.py`.

Suggested folders:

- `01-DIGESTS`: generated full video notes
- `03-REPOS-LINKS`: extracted links and repos
- `04-PATTERNS`: reusable lessons promoted from videos
- `05-CODEX-IMPORTS`: short notes for future Codex/Claude sessions
